# agrillm

**agrillm** is a system that turns informal decision questions into reproducible evidence‑based answers.

## Installation

You can install the development version of agrillm from [GitHub](https://github.com/) with:

``` r
# install.packages("remotes")
remotes::install_github("byzheng/agrillm")
```
